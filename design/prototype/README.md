# UI 原型（静态，示例数据）

这是「张导插件商店」界面重做的**评审用静态原型**，不参与生产构建，不影响 `src/` 下的应用代码。

## 怎么打开

直接双击 `index.html`（或在本目录起任意静态服务）。左侧选页面、视口与主题，右侧是真实渲染的预览；原型内部也能切换深浅主题。

- 页面：插件市场、插件详情、手机号进入、提交插件、个人中心、Studio（总览与插件管理）、Studio（AI / 下载源 / 账号）、组件与状态
- 视口：375 × 700、768 × 800、1280 × 800
- 主题：深色（基准）、浅色（同语义派生）

## 设计依据

1. 《「张导请回答」全局 UI 设计思路》§4 颜色、§6 字体、§7 布局与必查视口、§8 组件语言、§9 图标、§10 动效、§12 无障碍底线、§13 反模板规则
2. `ui-ux-kit`：反模板审查、对比度必须计算、状态必须完整
3. `https://www.dshplugin.store`：只参考其条目与路径的组织方式，不采用其视觉

直播画面（§5 枪灰 / 黄铜 / 暗红）与留言端信息架构（待分流、未回复、直播展示）在插件商店没有对应表面，未移植。

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.html` | 原型外壳：页面 / 视口 / 主题切换 |
| `prototype.css` | 设计令牌与组件层（深浅双主题） |
| `icons.js` | 内联 Phosphor Icons v2.1.1 sprite（MIT），不依赖远程字体 |
| `prototype.js` | 主题、标签页、状态切换与演示交互 |
| `market.html` `detail.html` `login.html` `submit.html` `me.html` | 公开端页面 |
| `studio.html` `studio-settings.html` | Studio 控制台 |
| `kit.html` | 组件、字阶、圆角与四种数据状态 |

## 已校验项

- 8 页 × 3 视口 × 2 主题 = 48 次真实渲染：无横向溢出、图标正常、每页单一 `h1`、触控目标不小于 44 × 44
- 28 组前景/背景对比度（深浅各 14 组）全部 ≥ 4.5:1
- 状态完整：正常 / 载入 / 空 / 错误四态在 `kit.html` 可切换查看

## 说明

所有数据为示例数据，未连接后端。原型通过后按 `prototype.css` 的令牌与组件落到 `src/styles/` 与 `src/components/`，并同步更新项目根目录的 `DESIGN_SYSTEM.md`。
