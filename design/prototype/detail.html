功能

  • 定时获取本机公网 IPv4 / IPv6 地址，并更新到对应的 DNS 服务商。
  • 支持阿里云、腾讯云、Cloudflare、Dnspod 等服务商；可同时启用多个。
  • 更新失败会保留上一次成功的记录，并在日志中给出失败原因。

安装

在本机下载 Release 中的 .ipk 后通过 LuCI 上传安装，或在设备上执行：

opkg install ./ddns-go_6.6.0_aarch64_cortex-a53.ipk
/etc/init.d/ddns-go enable
/etc/init.d/ddns-go start

配置

默认监听 0.0.0.0:9876，配置文件位于 /etc/config/ddns-go。

字段默认值说明
enable0是否启用服务
interval300检查间隔（秒）
provider—DNS 服务商标识

兼容性

需要 OpenWrt 21.02 及以上。低于该版本缺少依赖 libustream-openssl。
