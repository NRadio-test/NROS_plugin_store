提交插件

提交公开 GitHub 仓库链接。商店不接收上传的安装包，源码与 Release 始终由你维护。

只接受 github.com 的 HTTPS 公开仓库，不支持私有仓库、源码压缩包或网盘地址。

提交后会发生什么

  1. 读取仓库的 README、description、源码快照与最新正式 Release。
  2. 静态解析 Release 中的 .ipk，检查包内脚本与架构。
  3. 把以上材料送自动审核，结论为通过、拒绝或待补充。
  4. 通过后自动上架；之后每天两次检查仓库变化，新版本需重新审核。
提交者与 GitHub 作者是两个身份，商店不会把提交者记为仓库所有者。审核进度可在个人中心查看。

源码与安装包由作者发布于 GitHub。通过自动审核不保证无病毒。
