# 作者投稿指南

所有作品和新版本，包括管理员提交的作品，都必须经人工审核后上架。

## 1. 选择提交方式

直接上传 IPK 时：填写插件名称、用途简介、使用教程后选择不超过 32 MiB 的 .ipk 文件。无需 GitHub 仓库，也不要求提供二进制源码。教程请说明支持的设备、安装、使用和卸载方式。

有公开仓库时可切换到 GitHub：提交公开 HTTPS 仓库地址，在正式 Release 中附上 .ipk；多架构分别命名。README 和简介作为展示及人工审核材料，商店不执行仓库代码或构建。

## 2. 等待人工审核

后台先整理安装包与资料，随后显示“待人工审核”。此时作品不会出现在市场，也不能从公开下载接口获取。

管理员可查看资料和当前版本、下载安装包，选择通过并上架或退回修改。当前没有自动查毒；人工允许收录不表示已确认无病毒。

## 3. 查看反馈与修改

个人中心“我的提交”可按等待审核、需要修改和已上架筛选。退回时会展示具体原因；修改 GitHub 资料后同步新版本，或对直传作品上传新版本，重新送审。

待审作品没有公开详情入口。材料整理失败时会显示可重试的原因，不会当作人工通过。

## 4. 更新与下载

新版本必须重新审核，待审或退回期间旧的人工批准版本继续展示和下载。请发布新 Release，不要移动已经批准的标签或替换原附件；文件不一致时下载会停止。

GitHub 的 README 和 Release 安装包分别记录其来源版本；资料变动也先作为候选，不会直接覆盖已发布说明。危险 HTML 和链接在显示时过滤。

商店将安装包保存到用户设备，不自动安装，也不替用户猜测架构。收藏和下载继续使用原有业务规则。

## 5. 旧作品重新审核

本次切换将全部既有作品纳入人工审核，保留原文件、收藏和投稿关联。管理员重新通过后恢复公开展示。

管理员下架后不会自动恢复；显式恢复也需要重新审核。
