# 作者投稿指南

登录后进入「提交插件」，选择以下一种方式。所有投稿和更新版本都须人工审核。

## 提交 IPK

填写名称、简介和使用教程，再选择一个不超过 32 MiB 的 `.ipk` 文件。版本和架构从包内读取，无需 GitHub 仓库。教程应包含适用设备、安装与使用方法。

## 提交 GitHub 仓库

填写公开 GitHub 仓库地址，在正式 Release 中上传 `.ipk`。多架构安装包分别命名；详情页使用仓库 README。请补充许可信息，并发布新 Release 更新版本，避免替换已批准附件或移动旧标签。

## 查看审核与更新

在个人中心「我的提交」查看进度和退回原因。GitHub 投稿修改仓库资料后同步；直传投稿上传新版本时可更新名称、简介和教程。

新版本批准前不公开下载，原批准版本仍可用。材料整理失败可按错误提示处理后重试；管理员下架的作品需由管理员恢复并重新审核。

详情页右侧下载当前版本，「历史版本」下载此前批准的版本。选择与设备匹配的架构；文件已删除或被替换时无法下载。
